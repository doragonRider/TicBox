# TicBox 1.0.16

手机 App、手表 Local Bridge 和内置的 Magisk 模块统一为 1.0.16（versionCode 17）。

## 改进

- **换了一套应用图标，可以在“设置 → 外观 → 应用图标”里选。**
  - 新图标是一只扁平的圆形手表：双色表带、表壳内一圈细边、三点钟方向的小表冠，表盘上有分钟刻度点、十二点处的橙色标记和橙色秒针。
  - 有三种配色：**暖白**（默认）、**海军蓝**和**雾蓝**。暖白和海军蓝的表带、表壳和表盘取背景的同一色系，看起来不再是亮色底上的一块黑表。
  - 三种共用一个新的主题图标（单色）。
  - 默认的深色表盘会变成暖白，主屏幕上已有的图标不会消失。
  - 另外两个桌面入口改成了不表示图标样式的名字，以后重画图标也不用再改名。所以**在 1.0.15 里选了“石板蓝”或“白色表盘”的，请先在 1.0.15 里换回默认图标再升级**，不然升级后桌面上会找不到 TicBox。
  - 如果已经找不到了：主屏幕上有“当前表盘”快捷方式的话，用它打开 TicBox，在“设置 → 外观 → 应用图标”里点一下暖白。没有这个快捷方式，就只能用电脑运行 `adb shell pm enable dev.ticbox.companion/.MainActivity`。
- **健康详情页加了“月”。** 在“日”“周”后面多了一个“月”：以选中的日期结尾，往前一个月（例如 10 月 24 日到 11 月 23 日）。每天一根柱子，显示每日平均，并列出每天的数值。步数、心率、睡眠、血氧都有；其他指标用的是同一个详情页，也都有。
- **换日期时详情页不再整页刷新。**
  - 新日期的数据读完之前，页面继续显示原来的内容。读完后各个部分在原地更新，步数圆环之类的动画照常播放。
  - 打开详情页或换日期时，会顺带读进前 7 天和后一天。所以按“前一天”“后一天”或者切到“周”时，大多不用等。
- **步数的按小时柱状图。**
  - 每小时的柱子占满这一小时，相邻的柱子连在一起，中间没有间隔。
  - 很小的值（接近 0）不会再画到横轴下方，而是从横轴往上留出一个最小高度。为 0 的小时不画柱子。
  - 周和月的柱子也修了同样的问题。热量、距离、运动时长、爬楼的日视图用的是同一种柱子，也一起改了。
- 手表上的 Local Bridge 换成暖白这一款图标。

## 升级

1. 在手机上打开新的 `ticbox-phone-1.0.16-release-<commit>.apk` 安装，数据保留。Play 保护机制提示“App scan recommended”时，可以扫描后安装，也可以选择“More details”→“Install without scanning”。用电脑的话运行 `adb install -r`。
2. 手表上的 Local Bridge 只换了图标，可以在 TicBox 里按提示更新，不更新也不影响使用。Magisk 模块只是版本号跟着变了。

## 未在真机验证

- 新图标在真实桌面上和作为主题图标时的样子：只在 Robolectric 里按圆形和圆角方形遮罩、48 到 360 像素渲染过。
- 用默认图标从 1.0.15 升级后，桌面上的图标是否换成了暖白；以及上面那条找回入口的办法。
- 月视图读一个月数据要多久，以及预读前后几天对手机的负担。
- 换日期时各部分原地更新的效果：只在 Robolectric 里跑过。
