# TicBox 1.0.15

手机 App、手表 Local Bridge 和内置的 Magisk 模块统一为 1.0.15（versionCode 16）。

## 改进

- **应用图标改成扁平风格，可以在“设置 → 外观 → 应用图标”里选。**
  - 1.0.14 的图标太拟物、细节太多。现在只留下轮廓：往外收窄的表带、方肩表耳、三点钟方向的小表冠、两点钟方向的按键，再加十二点处一个琥珀色标记，全部是纯色。手表也画得更大，表带露出得更少。
  - 有三种配色：深色表盘（浅石板底、深色表壳，默认）、石板蓝（石板蓝底、浅色表壳）和白色表盘。三种共用一个主题图标（单色）。
  - 每种图标是一个单独的桌面入口，选中哪个就打开哪个，另外两个关掉。默认图标沿用原来的入口名，所以更新后主屏幕上已有的图标不会消失。
- **“当前表盘”快捷方式。** Android 不允许应用在运行时把桌面图标换成一张图片，所以“应用图标”下面多了一行“当前表盘”。点一下，桌面会询问是否在主屏幕上添加一个快捷方式，它的图标就是手表当前的表盘。之后手表换了表盘，TicBox 连着手表时快捷方式的图标会跟着换。只用真实手表的表盘，演示手表的表盘不会用上。
- 状态栏通知里的手表按同样的比例放大。
- 手表上的 Local Bridge 用深色表盘这一款图标。

## 升级

1. 在手机上打开新的 `ticbox-phone-1.0.15-release-<commit>.apk` 安装，数据保留。Play 保护机制提示“App scan recommended”时，可以扫描后安装，也可以选择“More details”→“Install without scanning”。用电脑的话运行 `adb install -r`。
2. 手表上的 Local Bridge 只换了图标，可以在 TicBox 里按提示更新，不更新也不影响使用。Magisk 模块只是版本号跟着变了。

## 未在真机验证

- 切换图标后各家桌面的表现：多久换上新图标，主屏幕上的旧图标是被移走还是被替换，最近任务里的 TicBox 是否还在。
- “当前表盘”快捷方式：桌面的添加确认，点开时是否回到已经打开的 TicBox，以及换表盘后图标是否更新。
- 新图标在真实桌面上和作为主题图标时的样子：只在 Robolectric 里按圆形和圆角方形遮罩、48 到 360 像素渲染过。
