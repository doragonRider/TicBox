# TicBox 1.0.12

手机 App、手表 Local Bridge 和内置的 Magisk 模块统一为 1.0.12（versionCode 13）。

## 改进

- **全量同步少等约 1 秒。** 1.0.11 的全量同步约 14.1 秒，其中运动库的辅助进程在读到运动表时才启动，要等约 1 秒。现在全量同步一开始就在后台启动它，和健康表的读取同时进行，读到运动表时它已经准备好了。
  - 只在全量同步时提前启动：全量同步要读运动表的每一页，一定会用到它。增量同步大多用不到，仍是需要时才启动。
  - 没开 root 运动采集，或者手表上没有运动应用时，不启动。
  - 同步提前结束时，还没启动完成的辅助进程随之结束，不算启动失败，下次照常启动。

## 升级

1. 用 ADB 安装新的手机 APK：`adb install -r ticbox-phone-1.0.12-release-<commit>.apk`，数据保留。
2. 在本地桥接页更新手表上的 Local Bridge。

这次只改了手表的 Local Bridge。手机 App 和 Magisk 模块只是版本号跟着变了，不更新也不影响。

## 未在真机验证

- 实际省下的时间：手表日志里 `Fitness helper started` 应出现在数据点那几页之间，运动表那一步（`fitness_record`）的耗时应从约 1.1 秒降到约 0.1 秒。
- 辅助进程启动时和健康表的读取同时进行，是否让数据点那几页变慢。
