# TicBox 1.0.2

手机 App、手表 Local Bridge 和内置的 Magisk 模块统一为 1.0.2（versionCode 3）。

## 改进

- 首次同步只读取最近 3 天的健康数据和训练明细。换手机、导入数据或重装后的第一次同步，不再把手表上的几万条记录全部重发一遍。会话（睡眠等）、训练摘要和运动摘要仍然全部同步。
- 手表上还有更早的数据时，健康页顶部显示横幅，说明哪个时间之前的数据还只在手表上，并提供“全部同步”。全部同步就是“立即全量同步数据库”，完成后横幅消失。
- 留在手表上的旧数据不会被每小时的检查一点点补过来，只在全部同步时一次读取。

## 升级

1. 用 ADB 安装新的手机 APK：`adb install -r ticbox-phone-1.0.2-release-<commit>.apk`，数据保留。
2. 在本地桥接页更新手表上的 Local Bridge。时间窗只对手表上还没有同步记录的档案生效，已经同步过的手机不受影响。

## 已知情况

- 横幅的状态只保存在内存中：应用重启后，要等下一轮同步读到健康数据才重新显示。
- 在“健康变更日志”页开启或关闭日志后，下一次同步仍会把健康数据完整地重发一次。

## 未在真机验证

- 首次同步的时间窗：判断有无旧数据的那一页、只读到最近 3 天、横幅的显示，以及全部同步后横幅消失。
- root 运动采集下按训练结束时间跳过旧训练的明细。
