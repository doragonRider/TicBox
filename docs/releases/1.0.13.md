# TicBox 1.0.13

手机 App、手表 Local Bridge 和内置的 Magisk 模块统一为 1.0.13（versionCode 14）。

## 修正

- **无线调试页的第一步指错了位置。** 它让人在手表的“设置 → 系统 → 关于”里连续点按“版本号”，但 TicWatch 的版本号在下一层“版本”（Versions）里。现在写成“设置 → 系统 → 关于 → 版本”，英文和繁体中文同样修正。

## 文档

- [README](../../README.zh-CN.md) 改成从零开始的新手教程：每项功能需要什么，从安装、配对、通知、本地桥接到第一次同步的六个步骤，换手机、更新、常见问题，以及 root 和手表模块的进阶用法。
  - 手机 App 默认直接在手机上安装，并说明了被 Play 保护机制或开发者验证拦截时的处理办法；用电脑的 ADB 安装改为可选。
  - 手表换到新手机时优先用“转移”保留数据；手表没有 Google 帐号时，可以从演示手表的终端打开转移确认页。重置只作为最后的手段。

## 升级

1. 在手机上打开新的 `ticbox-phone-1.0.13-release-<commit>.apk` 安装，数据保留。Play 保护机制提示“App scan recommended”时，可以扫描后安装，也可以选择“More details”→“Install without scanning”。用电脑的话运行 `adb install -r`。
2. 手表上的 Local Bridge 和 Magisk 模块只是版本号跟着变了，不更新也不影响。

## 未在真机验证

- 中文和繁体中文界面里，手表上“版本”这一层的实际名称。
