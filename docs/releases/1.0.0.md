# TicBox 1.0.0

TicBox 的第一个版本。手机 App、手表 Local Bridge 和内置的 Magisk 模块统一为 1.0.0（versionCode 1）。

## 内容

- 配对、首次设置和后台连接恢复；保留数据的解除配对。
- 通知同步（动作、文字回复，按应用设置声音和振动）、电话、媒体、表盘、设备设置、锁屏、紧急求助、手表找手机和手机找手表。
- 本地健康同步：手表 Local Bridge 经专用蓝牙增量读取健康记录，手机本地保存和查询；可选的 root 运动采集、健康数据库变更日志和健康监测设置。
- 工具箱：无线 ADB 与 root 两种连接，应用安装（APK、分包、XAPK / APKS / APKM 数据包）、应用管理、文件管理、剪贴板、终端、远程屏幕（可选 UDP 传输）。
- 勿扰同步；手机数据的导出与导入。
- 云功能（Mobvoi 账号与健康云、Google 账号复制与云同步、手表上网代理）默认关闭。

## 安装

请在电脑上用 ADB 安装手机 APK：

```bash
adb install -r ticbox-phone-1.0.0-release-<commit>.apk
```

直接在手机上打开 APK 可能被拦截，提示“App blocked to protect your device”，只能点“Got it”。这是因为本应用需要通知访问权限（Google Play Protect 会拦截以这种方式安装、且申请该权限的应用），且开发者没有在 Android 开发者验证中登记；两者都不适用于 ADB 安装。手机需先开启开发者选项和 USB 调试（或无线调试）。如果通知访问的开关是灰色的，到应用信息 → ⋮ →“允许受限制的设置”。详见 [README](../../README.zh-CN.md#安装)。

## 从 TicWatch 换到 TicBox

TicBox 使用新的包名 `dev.ticbox.companion`，与 TicWatch 可以同时安装，签名相同。

1. 在 TicWatch 中导出数据，勾选“手表配对身份”，然后在连接页断开连接。
2. 用 ADB 安装 TicBox（见上一节），导入该文件。TicWatch 导出的文件（包括加密的 `.twbackup`）可以直接导入。
3. 手表连上后按提示“建立关联”，重新授予通知访问、电话等权限，重新登录 Mobvoi 账号（如使用）。
4. 在手表上卸载 TicWatch 的 Local Bridge，从 TicBox 安装新的 Local Bridge 并重新允许读取和 root；进程内模块在手表模块页原地升级。
5. 一切正常后再卸载 TicWatch。

完整步骤见[数据迁移](../dev/data-migration.md#5-换包名从-ticwatch-换到-ticbox)。
