# TicBox 1.0.19

手机 App、手表 Local Bridge 和内置的 Magisk 模块统一为 1.0.19（versionCode 20）。

1.0.17 和 1.0.18 没有单独发布。从 1.0.16 升级的话，另见 [1.0.17](1.0.17.md)（照片表盘编辑器）和 [1.0.18](1.0.18.md)（发送后切换到照片表盘、再次编辑用原图、主页显示照片）。

## 改进

- **发送照片时显示进度。** 以前点“发送到手表”后，照片一存到手表上编辑页面就关了，切换表盘还在后台进行，容易让人以为已经完成。
  - 现在按钮下方会出现进度条，依次显示“正在处理照片”“正在把照片发送到手表”“正在把手表切换到照片表盘”，页面会自动滚到进度条所在的位置。
  - 全部完成后才回到照片表盘页面，并提示“手表已经在显示这张照片了”。
  - 中途返回的话，照片表盘页面上会继续显示进度。离开照片表盘页面也不会中断发送和切换，结果显示在屏幕底部的消息里。
  - 点“使用这个表盘”切换时也会显示进度。
- **表盘页面显示自定义的照片。** “手表 → 表盘”里照片表盘的卡片以前显示的是 Image 表盘的默认图片。现在和主页一样，显示手表上的照片，并按设置画出时间、日期和电量。换了照片之后，卡片会跟着更新。

## 升级

1. 在手机上打开新的 `ticbox-phone-1.0.19-release-<commit>.apk` 安装，数据保留。Play 保护机制提示“App scan recommended”时，可以扫描后安装，也可以选择“More details”→“Install without scanning”。用电脑的话运行 `adb install -r`。
2. 手表上的 Local Bridge 和 Magisk 模块这次没有变化，只是版本号跟着变了，不更新也不影响使用。

## 未在真机验证

- 进度按步骤前进：发送到手表这一步的长短取决于蓝牙，进度条在这一步里不会随传输走动。
- 表盘页面要先认得哪个是照片表盘，才会画出照片：要打开过一次照片表盘页面，或者用 TicBox 切换过一次。
- 表盘页面如果还没取过手表上的照片，会向手表要一次（每次连接最多一次），所以照片表盘的卡片可能要稍等一下才出现。
