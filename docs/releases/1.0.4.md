# TicBox 1.0.4

手机 App、手表 Local Bridge 和内置的 Magisk 模块统一为 1.0.4（versionCode 5）。

## 修复

- 健康变更日志无法读取状态，也无法开启：手表上的 root 辅助进程在打开官方数据库时总是以 `SecurityException` 失败。原因是它降到官方应用的 UID 之后，SQLite 第一次打开数据库要经系统 context 读取一项全局设置，这个调用因包名和 UID 不符被系统拒绝。现在在降权之前先完成这次读取。

## 诊断

- 变更日志辅助进程失败时，手表日志还会记录抛出异常的代码位置（只有类名和方法名）。
- 手表日志记录每次采集计划读取的范围、近期范围被多少个会话向前扩展，以及每次预读读了多少行、用了多久，用来查增量同步为什么慢。读取方法见[健康数据 · 排查](../dev/health.md#6-排查)。

## 升级

1. 用 ADB 安装新的手机 APK：`adb install -r ticbox-phone-1.0.4-release-<commit>.apk`，数据保留。
2. 在本地桥接页更新手表上的 Local Bridge。
3. 在“健康变更日志”页重新读取状态，再按需开启。开启后的下一次同步会把健康数据完整重发一次。
