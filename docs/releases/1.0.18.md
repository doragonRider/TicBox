# TicBox 1.0.18

手机 App、手表 Local Bridge 和内置的 Magisk 模块统一为 1.0.18（versionCode 19）。

## 修复

- **发送照片后手表会切换到照片表盘。** 以前照片只是存到了手表上，手表上的照片表盘（叫 Image）默认不在收藏里，所以手表没有反应，“使用这个表盘”也切换不过去。
  - 现在“发送到手表”成功后，以及点“使用这个表盘”时，TicBox 会先把 Image 表盘加到收藏里，再把它设为当前表盘，和手动在“表盘 → 更多表盘”里添加再选择是一样的。
  - 已经是当前表盘的话就不再切换。找不到这个表盘或者手表拒绝添加时，会提示到“更多表盘”里手动添加。
- **再次编辑不会再变成 300 × 300。**
  - 手表只能返回宽 300 的预览，以前离开照片表盘页面后再编辑，用的就是这张小图。
  - 现在手表接受照片后，TicBox 会在手机上保留选中的原图，以及当时的取景、缩放算法和锐化设置，再次编辑时从原图开始。
  - 原图存在 App 的私有目录里，不参与系统备份。只保留最后一张发送成功的照片，超过 64 MB 的照片不保留。
  - 从来没用 TicBox 发送过照片时，编辑的仍然是手表上的预览，页面会提示比屏幕小。
- **主页显示自定义的照片。** 照片表盘是当前表盘时，主页上的手表和“当前表盘”快捷方式以前显示的是 Image 表盘的默认图片。现在显示手表上的照片，并按设置画出时间、日期和电量。

## 升级

1. 在手机上打开新的 `ticbox-phone-1.0.18-release-<commit>.apk` 安装，数据保留。Play 保护机制提示“App scan recommended”时，可以扫描后安装，也可以选择“More details”→“Install without scanning”。用电脑的话运行 `adb install -r`。
2. 手表上的 Local Bridge 和 Magisk 模块这次没有变化，只是版本号跟着变了，不更新也不影响使用。

## 未在真机验证

- 在真实手表上自动添加并切换到 Image 表盘：用的是 TicBox 已有的收藏协议，但照片表盘设置里的类名能否和表盘目录对上，只在演示手表上试过。
- 主页识别照片表盘：要先打开过一次照片表盘页面，或者用 TicBox 切换过一次，TicBox 才认得它。
- 再次编辑时取景是否和上次一致：同一张原图每次读入的尺寸相同，所以应当一致。
